# 全局工作数据备份

## 范围

用户手动保存全部已保存的工作数据，不备份代码，不支持定时或节点备份。内容包括活动（含归档）、逻辑屏幕、原始素材、场景分区/叠加/特效和语言偏好；不包含配对凭证、网络设置、播放状态或其他备份。跨电脑恢复后重新配对，等待人工执行场景。

## 文件与目录

server/work-backups.js 固定使用 TOPARROW_DATA_DIR/backups，不接受客户端路径。首次创建备份时才建目录；拒绝备份目录和文件的符号链接。文件名为 StagePilot-本机日期-时间-UUID.spbackup。先写 .partial 临时文件，完成后原子重命名；失败清理临时文件。权限、空间、缺失素材错误不会显示成功。

列表扫描磁盘上符合本应用命名规则的真实文件，读取头部名称/时间/数量，按修改时间与大小缓存，不另建数据库记录。文件或目录被删除后，下次两秒轮询或手动刷新自动消失。损坏元数据不列入可恢复列表；恢复时仍校验完整文件和摘要。名称是创建时写入文件的说明。未自动清理历史备份。

server/backup-file.js 采用 STAGEPILOT-DATA-1 二进制格式，兼容此前 .stagepilot：魔数、4字节JSON长度、元数据、原始素材字节、32字节SHA-256摘要。每份素材独立摘要，按64KB块流式处理，最大文件4GB、元数据16MB、总记录2万、单素材256MB。摘要用于损坏检测，不提供加密或来源认证。名称、归属、布局、引用和类型严格验证；导入不执行代码、不接收包内文件路径，新UUID重建全部实体和素材引用。

## API 与恢复保护

只在本机管理服务开放，沿用 Host、Origin、CSRF 校验。局域网显示服务不提供这些接口。

- POST /api/backups/list：返回真实文件列表和固定目录。
- POST /api/backups/create：停播且关闭LAN，手动创建备份。
- POST /api/backups/open：只接受列表ID，系统文件管理器定位选中文件。macOS使用系统open，Windows使用系统资源管理器；无shell命令拼接、不接受任意路径。
- POST /api/backups/delete：confirm=true，删除磁盘文件，当前工作数据不变。
- POST /api/backups/preview：复制选中的本机文件到数据目录tmp，校验并返回内容清单。
- POST /api/backups/upload：流式接收选择的外部文件，在tmp校验并暂存，不修改当前工作。
- POST /api/backups/cancel：删除对应预览暂存。
- POST /api/backups/restore：confirm=true且目标数据指纹与预览相符，先保存当前工作的安全备份；失败则不恢复。外部来源文件保留到备份列表，再以事务替换工作数据。素材用新UUID文件名先就位；事务失败清理新文件，旧数据与媒体保留。成功后清理旧媒体并清除配对及上次播放快照。

导入预览15分钟有效，最多3份；过期、取消或退出清理暂存。启动前清理中断留下的 work-backup-UUID 暂存。生成/校验/恢复期间维护锁拒绝其他写请求，列表和健康检查仍可用；备份恢复要求停播且关闭LAN。没有定时备份；只有确认恢复时自动保留一份恢复前安全备份。

## 验证边界

自动测试覆盖空目录首次创建、文件删除联动、路径/符号链接拒绝、凭证排除、跨数据目录恢复并继续编辑、损坏与未来版本拒绝、事务失败回滚、过期目标指纹、确认保护及恢复前安全备份还原。macOS界面验证了手动生成、列表、访达选中文件、恢复清单与确认保护。Windows系统文件管理器、电视和接近4GB文件需实机验收。
