# 本机运行与打包

## 运行

在顶箭“我的发布”中打开本项目。平台按 manifest.json 使用自带 Node 24 执行 server/index.js，提供 TOPARROW_APP_PORT 和 TOPARROW_DATA_DIR。应用不自行选择主控端口、不内置运行时、不依赖在线资源。

缺少或非法环境变量、数据目录不可写、数据库初始化失败时，入口明确输出启动错误，不回退到源代码目录。运行日志在数据目录 logs/stagepilot.log，超过1MB轮换一份。

打开后从侧栏或右上角“使用指南”开始。也可在主控地址后加 /#help 直达指南。

## 发布包准备

1. 使用顶箭自带 Node 执行 scripts/package.js。
2. 脚本仅把 manifest、icon、server、public、lang、vendor 放入 release/StagePilot，同时生成 StagePilot.zip 源文件包。ZIP不是顶箭安装包。
3. 使用顶箭自带 tactl 执行 `pack release/StagePilot --out release`，生成 stagepilot.topapp。
4. 发布前再按 _doc/aicode/rules/publish_check.md 逐节检查，并在 Windows、Mac 和目标电视实机验收。

不直接打包整个开发根目录，避免把 data、.git 或临时验证文件带入。release/ 已被 Git 排除。所有第三方运行依赖和许可证随包提供。

本次只生成本地测试包，未安装额外应用实例、未上传市场、未发布。
