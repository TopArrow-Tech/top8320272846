# 幕控 StagePilot MVP 测试

## 自动化

使用顶箭 Node 24 执行 `--test tests/integration.test.js`。数据位于 data/tmp/integration-*，成功运行后删除；服务使用临时端口，测试局域网流程时短暂绑定当前私有网卡。测试不修改用户活动。

覆盖：错误运行环境；布局越界及跨活动引用；健康检查；CSRF/Origin/Host；禁止读取源码；图片上传与伪装文件拒绝；素材引用保护；HTTP 提示确认；默认关闭局域网；错误配对码；主控批准与防重复批准；WebSocket 认证及场景时间；受保护素材与 Range；暂停继续；撤销授权；重启后关闭网络、保持待命及人工恢复。

## 本机浏览器

- 创建活动、添加逻辑屏幕、添加文字、使用字幕分区、保存场景。
- 切换语言，检查标签、布局和错误文案。
- 素材导入，预览图片和视频；图层叠加、拖动、层序、静音/音量。
- 配对后执行场景，查看版本、准备状态、偏差。

## 交付后必须实机验证

以下不能用接口测试代替，当前不得标记通过：

1. 顶箭「我的发布 → 打开」启动并通过平台健康检查。
2. Windows 10+ 与 Apple Silicon macOS 11+ 启动、上传、重启和打包安装。
3. 每种实际电视的浏览器/固件，遥控器聚焦按钮、全屏、有声播放、视频解码。
4. 同一视频分配到至少两台设备，运行 30 分钟，记录各设备偏差；用高速摄影或同画面计时码观察实际同步，不能只凭软件上报认定逐帧同步。
5. 各屏独立发声、音量和静音，浏览器拒绝自动播放时的再次授权。
6. 断 Wi-Fi、拔网线、IP 变化、电脑睡眠、主控重启、网卡失效、防火墙拦截。
7. 真实素材：1080p / 4K、长视频、并发设备、弱网、磁盘不足、数据目录不可写、上传中断。
8. 数据不会进入发布 ZIP；平台安装后的数据目录与开发目录相互独立。

## 已知限制

- HTTP 明文，限定可信局域网，不支持公网和自动设备发现。
- 不保证逐帧同步；老旧电视不保证兼容，视频不自动转码。
- 视频断网只能播放现有缓冲，不承诺完整离线播放。
- 单个素材最大 256MB，单屏最多 24 图层；复杂度应按设备性能控制。

## 多屏独立场景回归

自动化已验证：第一屏执行场景A，再给第二屏执行场景B，第一屏 config/cue/startAt/version 保持一致，旧素材仍可访问；再执行A时第二屏不变。重启后人工恢复同时包含A和B。未配置任何屏幕的场景被拒绝。

## 输入与录屏导入

自动化验证空白/小数中间态、全角数字、前导零、上下限、步长及非法字符。浏览器验证字号清空→20、020失焦→20、保存成功。MOV 验证常见容器头与QuickTime MIME、伪装文件拒绝；真实录屏HEVC/H.264及各电视播放仍需实测。

## 删除与提示隔离

验证未确认不删除；引用变化后旧确认失效；确认删除素材移除引用图层且只停止使用该素材的屏幕，另一屏cue/时间轴保留；删除逻辑屏幕后设备解除分配、场景移除该屏配置但场景保留。浏览器验证A页面错误不带到B页面、确认框列出影响且取消不修改内容。

## 移除备份和数据导出

验证侧栏、连接页和帮助中没有备份或数据迁移入口；旧备份、导入恢复、导出API均返回404。活动、素材、场景、归档管理及展示恢复仍正常。已生成的历史备份文件已按用户要求删除。
