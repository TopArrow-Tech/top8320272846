# 2026-11-10 幕控 StagePilot 多屏 MVP 与使用指南

## 原因与范围

从顶箭空模板实现面向普通用户的局域网多屏展示工具。用户确认中英双语、深蓝/青绿、“联屏指挥”图标、Node/React/SQLite、电视浏览器、分区图文视频叠加、独立声音及连接码+主控确认。用户已进一步接受浏览器校时校正方案（精度实测、不承诺逐帧）及可信局域网 HTTP 明文。

## 变更

- server/：平台环境变量适配、健康检查、SQLite 关系模型、活动与复制、屏幕、素材、场景、运行快照、受保护的视频 Range、按需 LAN、设备配对和撤权、WebSocket 时间/状态协议、备份恢复。
- public/：React 本机主控台、无 React 依赖的显示端、深蓝青绿响应式主题、比例图层编辑、场景控制、错误及状态提示。
- lang/：中英集中语言文件；所有主要页面、显示端、错误与操作指南使用语言字典。
- public/app.js：补充侧栏与顶部“使用指南”，八步流程、页面跳转、六类常见问题；#help 可直达。首次无活动也可查看手册。
- icon.png：imagegen 内置工具生成“深蓝底，三个青绿联动屏幕及中央播放控制节点，无文字”的专属图标；缩小到448×448，184896字节。
- scripts/package.js：白名单源文件打包，排除 data、Git、开发文档和临时文件；可生成 source ZIP 与供官方打包的 release/StagePilot。
- manifest.json：stagepilot，Node24入口，局域网声明；不填写版本号。
- _doc/使用手册.md、User_Guide.md：与应用内指南一致的双语手册。
- _doc/projectinfo/：总体结构、数据、安全、同步及恢复设计。
- tests/、_doc/testcase/：自动化与实机测试边界。

## 限制

HTTP不加密；现代电视浏览器能力为前提；不自动转码；断网视频只保证已有缓冲；不能保证逐帧同步。单文件256MB，单屏24图层，最多64个显示端连接，实际并发承载需按硬件与网络测试。备份包含配对记录，只在本机数据目录保存。

## 多屏独立执行修复

用户反馈执行仅含第二屏的场景会清空第一屏。server/index.js 改为同活动只合并显式配置的屏幕，screenStates 分别保存场景、cue、版本与时间轴；未涉及屏幕保持原时间轴，跨活动仍完整切换。全局暂停/继续按各屏时间轴处理；恢复记录保存多屏配置快照；保护所有正在播出的场景，避免只检查最后执行场景。

public/app.js 显示多屏当前播出列表、每台设备对应场景及独立执行说明；lang 与中英文手册同步说明空图层显式清屏、多个屏幕同场景统一切换。

回归测试使用两个独立认证 WebSocket 客户端，验证第二屏切换不改变第一屏配置、cue、startAt、版本和素材授权，反向切换同样保留；验证重启人工恢复包含两屏。共8项测试全部通过。

## 中文菜单与图层特效

- public/app.js：显示端地址拦截原生右键菜单，提供跟随语言的打开、复制、取消，支持键盘入口/Escape；增加复制兼容回退；补齐本机和控制台标签中文。
- public/effects.js、public/display.js、public/styles.css：四向滚动、淡入淡出、呼吸缩放；图片/文字/视频均可使用。图层区域裁切、长文字滚动、共享动画时间计算、暂停/重连跟随屏幕时钟。
- server/validation.js、server/index.js：特效参数白名单与时长校验、旧场景默认无特效、共享脚本静态路由。
- lang/ 与双语手册：特效设置、每轮时长和使用方式。
- 自动化11项检查通过（包括特效下发与多屏回归）；本机浏览器验证滚动预览保存及中文右键菜单，未发现浏览器错误。真实电视效果与流畅度仍待实机验证。

## 输入框与 MOV 导入修复

- public/number-input.js、public/app.js：数字编辑保留原始文本，允许空白和小数中间状态；有效值可实时预览，失焦/Enter 时去前导零、步长规范化、边界修正；Escape 恢复最后有效值，方向键微调，聚焦选中，兼容全角数字和输入法。统一用于字号、坐标/尺寸、场景顺序和特效时长。坐标与尺寸上限相互约束，避免越过画布导致保存失败。
- public/styles.css：统一文本、数字、多行和选择框高度、间距、字体、边框与聚焦提示；移除数字原生步进框造成的显示差异，保留键盘增减能力。显示端连接码过滤非数字并兼容全角数字，保留前导零。
- server/index.js：加入 MOV 扩展名、QuickTime MIME 与常见容器头识别；允许导入不代表设备能够解码，不包含转码器。
- public/app.js、lang/：文件选择器加入 MOV，明确兼容性说明；任何操作失败时清除过时进度提示，防止仍显示正在导入。
- 新增数字编辑回归测试，15项自动化检查全部通过；浏览器验证字号可清空后输入20、粘贴020后失焦显示20并正确保存，无控制台错误。MOV测试只验证容器识别及伪装文件拒绝，未对用户录屏的实际编码做验证。

## 删除流程与页面提示修复

- server/deletion.js：统一活动、逻辑屏幕、场景、素材删除的影响预览及确认。列出场景引用、正在使用的屏幕及会解除分配的设备；对确认内容计算指纹，执行前重新校验，变化时要求重新确认。
- 数据库事务解除引用并删除；素材删除移除对应图层，屏幕删除移除对应屏幕配置，场景本身保留。活动删除仍级联删除其内容。正在使用时只有确认后才停止受影响的输出，未涉及屏幕保留原内容和时间轴；同步清理人工恢复快照。
- public/app.js：删除影响确认框、双语说明；页面/活动切换清除提示，并通过操作代次隔离异步返回的旧操作提示。
- 自动化16项检查通过，新增引用清理、确认过期、设备解绑和保留其他屏幕回归。浏览器验证错误发生后切换页面提示清空，删除屏幕显示引用与设备影响，取消后未删除内容。

## 归档管理与跨电脑数据迁移

- public/app.js、lang/：独立归档管理和数据迁移入口；活动管理和顶部选择器只列未归档活动；归档搜索、内容清单、恢复及既有删除影响确认。正在展示的活动禁止直接归档。
- server/migration.js：版本化 .stagepilot 容器，JSON业务清单加素材原文件及SHA-256完整性校验，流式读写，最大4GB；严格验证版本、数量、归属、布局、类型、体积和摘要；不使用包内路径。
- server/index.js：生成迁移包/限时下载、上传校验、预览、取消、合并与整库替换；维护期间拒绝其他写入。下载30分钟、导入预览15分钟有效，临时文件到期清理。
- 合并为全部导入实体重建UUID并重新映射外键与素材引用，同名活动加数字后缀，不覆盖已有活动。归档、备注、特效和素材字节完整保留。整库替换需额外确认及目标数据指纹，先完成本机完整备份再事务替换；失败不替换业务表。
- 迁移包只包含业务数据及界面语言，不包含设备凭证、网卡地址、端口、日志、已有备份和运行状态。替换会清除目标电脑配对记录；合并保留目标已有配对。
- 自动化18项通过：迁移往返、归档/特效/素材、ID重映射、凭证排除、损坏与不兼容包拒绝、失败保留旧数据、合并、替换确认过期、自动备份及恢复。
- 浏览器验证归档活动恢复、实际下载 .stagepilot、重新上传校验并显示预览、默认合并、替换未勾选时按钮禁用；界面测试取消导入，未执行替换。真实Windows/顶箭内嵌浏览器下载行为及大体积压力仍待目标环境实测。
